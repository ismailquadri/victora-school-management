# Victora — School Management System

Victora is a modern, responsive, and feature-rich School Management System dashboard designed for academic institutions, administrators, teachers, and students.

![Victora Dashboard Preview](Preview/Dashboard%20mockup.png)

## 🌟 Key Features

- **Multi-Campus Administration**: Real-time overview of campus KPIs, capacity utilization, student/teacher ratios, and collection rates across districts.
- **Student & Staff Directory**: Manage student enrollments, guardian contacts, records, and academic status.
- **Attendance & Gate Check-in**: Streamlined daily attendance logging, automated gate check-ins, and instant guardian notifications.
- **Academic Timetable & Scheduling**: Interactive schedule management with conflict resolution and one-click calendar publishing.
- **Fee Management & Invoicing**: Track invoice status, overdue balances, collection trends, and export billing data.
- **Assignments & Grading**: Track homework, quizzes, and project submissions with real-time progress indicators.
- **Internal Messaging**: Integrated messaging system connecting teachers, guardians, and administration.

### Quick Start

To run locally, simply serve the root directory using any static file server:

```bash
# Using Python
python3 -m http.server 8000

# Using Node.js
npx serve .
```

Open your browser at `http://localhost:8000`.
